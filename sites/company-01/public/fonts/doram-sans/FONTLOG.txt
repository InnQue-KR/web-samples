FONTLOG — Doram Sans (company-01 sample site)
=============================================

What this is
------------
Doram Sans is a Modified Version of "Pretendard Variable" 1.3.9
(Copyright (c) 2021, Kil Hyung-jin, https://github.com/orioncactus/pretendard,
with Reserved Font Name Pretendard), licensed under the SIL Open Font License 1.1.
See LICENSE.txt in this folder (identical text to
https://raw.githubusercontent.com/orioncactus/pretendard/v1.3.9/LICENSE).

Because it is modified, it does not use the Reserved Font Name. The family,
full, PostScript, unique-ID, variations-prefix and named-instance names were
changed to "Doram Sans" / "DoramSans". Copyright (nameID 0), trademark (7),
manufacturer (8), designer (9), URLs (11, 12) and license (13, 14) were kept
as in the original. nameID 5 (version) and 10 (description) record the change.

Changes from the original
-------------------------
- Source file: npm pretendard@1.3.9, dist/web/variable/woff2/PretendardVariable.woff2
  SHA-256 9599f12fd42fc0bce1cd50b47a0c022e108d7aa64dd0d1bb0ed44f3282d900b4
- Glyph subset only: the characters used by the company-01 sample site
  (HTML, script and style text of the built site) + all printable ASCII
  + a fixed list of common symbols. Exact list: manifest.json "unicodeRange".
- Not changed: glyph outlines, the variable weight axis (wght 45-930),
  advance widths, kerning, all OpenType layout features (GSUB/GPOS kept for
  the remaining glyphs), head.modified timestamp. Rendered text of the site
  is pixel-identical to the unsubset original in Chromium (INNA-653 check).
- Tool: fontTools 4.68.0 subset + brotli 1.2.1 (WOFF2), pinned with hashes in
  sites/company-01/scripts/font-requirements.txt.
- Generator: sites/company-01/scripts/make-font-subset.py (deterministic:
  the same inputs give the same SHA-256, recorded in manifest.json).
