> 이 문서는 **가상 샘플 사이트** `landing-01`을 기준으로 쓴 고객용 운영 안내 초안입니다. 셈틈 수학학원은 실제 업체가 아니며, 아래의 계정·주소·요금은 실제 주문에서 고객 정보로 채웁니다. `[ ]` 안은 아직 정해지지 않은 값입니다. 정해지지 않은 값을 실제처럼 채워 넣지 않습니다.

## 2. 소유 계정

실제 납품에서는 아래 계정을 **고객 명의**로 만들고 InnQue는 초대받은 권한으로만 작업합니다. 비밀번호를 채팅·메일·문서로 주고받지 않습니다.

| 계정 | 소유자 | InnQue 권한 | 납품 뒤 |
|---|---|---|---|
| 도메인 등록·DNS | 고객 | 필요한 기간에만 DNS 편집 초대 | InnQue 권한 해제 |
| GitHub 저장소 | 고객 | 쓰기(Collaborator) | 유지보수 계약이 없으면 해제 |
| 호스팅(예: Cloudflare Pages) | 고객 | 프로젝트 관리 | 같음 |
| 폼 서비스(선택) | 고객 | 설정 기간에만 | 해제. 응답 열람 권한은 원칙적으로 받지 않음 |
| GA4(선택) | 고객 | 편집자 | 해제 |

계정 복구용 이메일·전화는 **학원 대표 또는 지정 담당자 본인**의 것으로 둡니다. InnQue 직원 메일을 복구 수단으로 넣지 않습니다.

## 3. 로그인 보안(MFA)과 복구

- 위 모든 계정에 2단계 인증(MFA)을 켭니다. 문자보다 인증 앱·보안 키를 권합니다.
- 각 서비스의 **복구 코드**를 인쇄하거나 비밀번호 관리자에 보관합니다. 사진으로 메신저에 보내지 않습니다.
- 담당자가 바뀌면 새 담당자를 먼저 추가하고, 로그인 확인 뒤 이전 담당자를 지웁니다.
- 계정이 털렸다고 의심되면: ① 비밀번호 변경·다른 기기 로그아웃 ② MFA 다시 설정 ③ 저장소·호스팅의 최근 변경 기록 확인 ④ InnQue에 알림(유지보수 계약이 있으면 복구를 돕습니다).

## 4. 요금과 갱신

| 항목 | 누가 내나 | 확인할 것 |
|---|---|---|
| 도메인 | 고객 | 연간 갱신일과 자동 갱신 카드. 만료되면 사이트와 메일이 함께 끊길 수 있음. 금액은 등록업체 견적 기준 `[ ]` |
| 정적 호스팅 | 고객 | 무료 플랜의 한도(빌드 횟수·파일 수 등). 무료 한도와 정책은 바뀔 수 있으며 영구 가격 약속이 아님 |
| 폼 서비스(선택) | 고객 | 무료 플랜 범위, 유료 전환 조건. InnQue가 대신 결제하지 않음 |
| GA4(선택) | 고객 | 표준 속성은 무료. 광고비·유료 분석은 별도 |
| 수정 대행 | 고객(주문 시) | 건별 견적 또는 별도 유지보수 계약. 자동 가입 없음 |

이 샘플 자체에는 결제한 서비스가 없습니다(결제 0원).

## 7. 문제가 생겼을 때

| 증상 | 먼저 할 일 | 되돌리기 |
|---|---|---|
| 배포(빌드)가 실패함 | 호스팅 화면의 빌드 기록에서 실패 메시지 확인. 실패하면 **직전 정상 배포가 그대로 유지**됨 | 마지막 변경을 되돌리는 커밋 후 다시 배포 |
| 화면이 깨짐 | 다른 브라우저·시크릿 창에서 확인, 캡처와 주소를 보내 주기 | 호스팅의 이전 배포로 롤백 |
| 사이트가 안 열림 | 도메인 만료·DNS 변경 여부, 호스팅 상태 페이지 확인 | DNS 기록을 바꾸기 전 값으로 복원 |
| 폼 알림이 안 옴(실제 납품) | 폼 서비스의 응답 목록과 스팸함 확인. 알림 도착과 실제 제출 기록은 따로 확인 | 급하면 폼을 닫고 전화 안내만 남김 |

긴급 24시간 대응은 별도 계약이 없으면 포함하지 않습니다.

## 8. 샘플 폼과 실제 고객 전환의 차이

이 샘플의 [상담 신청 보내기]는 **입력 형식만 검사**하고 "샘플 사이트라 실제로 전송되지 않습니다"를 보여 줍니다.

- 입력값은 네트워크·주소창·콘솔·쿠키·브라우저 저장소 어디에도 남기지 않고, 확인 직후 화면에서도 지웁니다.
- 자바스크립트가 꺼져 있거나 실패하면 입력 칸과 버튼이 잠긴 채로 있어 아무것도 제출되지 않습니다.
- 개인정보 안내문도 "저장·전송하지 않는 시연"이라는 실제 동작을 설명합니다.

실제 납품으로 바꿀 때는 아래를 **새로 확인**해야 하며, 확인 전에는 폼을 공개하지 않습니다.

1. 폼 서비스와 처리 국가, 국외 이전 고지·동의 문안(납품 표준 6절), 수집 주체·목적·항목·보유 기간·문의처를 실제 값으로 채운 동의문
2. 테스트 제출 → 고객 수신함 도착 확인 → 응답·메일 사본 삭제까지 한 번 실행
3. 스팸 방지 설정과, 차단될 때 쓸 전화 안내
4. "접수 완료"는 폼 서비스의 성공 신호가 확인될 때만 표시

## 9. 버튼 클릭 측정(3종) — 시연 확인 방법(QA·영업 시연용)

방문자 화면에는 측정 표시가 없습니다. 확인하려면 데스크톱 브라우저에서:

1. 사이트를 열고 개발자 도구(F12) → Console을 엽니다.
2. `sampleTrack.events()` → `["cta_hero_apply", "cta_sticky_apply", "cta_phone"]` 3개가 나옵니다.
3. 첫 화면 [겨울방학 상담 신청하기], 머리말 전화 아이콘, 오시는 길 [전화하기]를 누릅니다. 휴대폰 크기(폭 768px 미만)로 바꾸면 하단 고정 [상담 신청]도 누를 수 있습니다.
4. `sampleTrack.counts()` → 예: `{ cta_hero_apply: 1, cta_sticky_apply: 1, cta_phone: 2 }`
5. 새로고침하면 모두 0으로 돌아갑니다.

이 값은 **이 브라우저 탭의 메모리에만** 있습니다. 외부로 보내지 않고 저장하지 않으며, 접수 완료 수는 세지 않습니다. 이 시연은 **실제 GA 설치나 전환 실적이 아닙니다.** 실제 납품에서는 고객 GA4 속성에 같은 이름 3종을 연결하고, 동의 전에는 태그를 불러오지 않으며, 전화번호·문의 내용을 이벤트 값에 넣지 않습니다. 실제 GA 연동·DebugView 확인은 이 샘플에서 하지 않았습니다(미실시).

## 10. 다른 곳으로 옮기기(이전)

- 이 사이트는 빌드 결과 `dist/` 폴더만 있으면 정적 파일을 올릴 수 있는 어느 호스팅에서나 열립니다. 호스팅에 Node.js가 없어도 됩니다.
- 하위 경로가 `/landing-01/`로 고정되어 있습니다. 도메인 맨 앞(`/`)에서 열려면 `astro.config.mjs`의 `base`를 바꾸고 다시 빌드합니다.
- 옮길 때 넘겨받는 것: 소스 ZIP(또는 저장소), 배포 ZIP, `docs/assets.csv`와 라이선스, 이 안내서.
- 국내 웹호스팅은 업체 이름만으로 판단하지 않고, 가입한 상품이 정적 파일 업로드·HTTPS·폴더별 `index.html`·오류 페이지를 지원하는지 먼저 확인합니다.
- 도메인 연결을 바꿀 때는 기존 메일(MX 등) 기록을 지우지 않습니다.

## 11. 사용한 자원과 AI

- 글꼴: Pretendard 1.3.9(SIL OFL 1.1) 공식 파일을 **바꾸지 않고** 사이트에 함께 올립니다. 라이선스 원문을 함께 둡니다.
- 아이콘: Lucide(ISC) 7개를 인라인 SVG로 사용.
- 로고·일러스트·약도·공유 이미지: InnQue 디자인팀이 직접 그린 그림입니다. AI 생성 이미지가 아니며 실제 사진·지도·인물이 아닙니다.
- 기획·문구·이미지 제작 과정에 AI를 활용했고 사람이 검토했습니다(바닥글에 표시).
- 전체 목록: `docs/assets.csv`. 실제 납품에서 고객 사진으로 바꾸면 이 목록과 그림 설명(alt)을 함께 고칩니다.

## 12. 이 안내서에서 정하지 않은 것

- 실제 공개 주소, 호스팅 계정, 저장소 주소 — 배포 승인 전이라 비워 둠
- 폼 서비스와 국외 이전 문안 — 서비스 선택 뒤 작성
- 실기기(iPhone·Android)·Safari·화면낭독기 확인 — 독립 QA 과제에서 진행
